# Changelog

## [Unreleased]

- FIN-148: перед заменой версии Action получает состояние кандидата из кластера. Выкатка с существующим кандидатом блокируется. Откат возвращает предыдущую рабочую версию и ждёт подтверждения переключения.

- FIN-148: ручные Actions выкладки и отката передают токен из окружения сервиса в общий workflow по имени.

- FIN-148: Общий workflow проверяет CI текущего main и публикует закрытый Helm-пакет одного сервиса для Argo CD.

- FIN-530: новые коммиты отменяют прежние PR-проверки и relay приватного CI; имена обязательных проверок сохранены.

- FIN-517: добавлен доверенный relay приватного CI сервисов в infra с проверкой точной попытки, обязательных результатов и изоляцией PR-кода от секретов.

- FIN-516: повтор CI завершает публикацию успешно для существующего неизменяемого тега, впервые опубликованного до перехода на воспроизводимые образы.

- FIN-516: сборка образов сервисов фиксирует метки времени по коммиту для идемпотентного повтора публикации.

- FIN-516: поддержаны вызовы Go CI из защищённой ветки main и привязка приватных зависимостей к SHA фактической попытки CI.

- FIN-513: обновлены Go до 1.27.4, Squawk, actionlint, Renovate и анализатор покрытия. Проверка порога покрытия сохраняет согласованное округление.

- FIN-491: добавлена доверенная подготовка приватного Go CI для пилота assistant. PR-проверки получают закреплённый исходник и проверенные зависимости без токена к другим репозиториям.

- FIN-451: контроллер Renovate повторно проверяет свежесть PR перед записью quarantine/recovery и уведомлением о потраченном retry claim; поздний конфликт блокирует эти записи, сохраняя budget. Добавлены отрицательные lifecycle-тесты. Изменение касается только автоматизации репозитория.

- FIN-456: контроллер Renovate и его Python/JS lifecycle-регрессии централизованы в `common/renovate/` и composite actions для 19 репозиториев. Сохранены late-conflict guards FIN-451, ручные Go updates, Compose, stage CI и durable receipts; config/runtime lock/state остаются данными потребителя. Source использует main-only локальную action без циклического self-SHA.

- FIN-430: добавлены профильные QA-навыки в каталог ревью (ai-qa-review), переносимые правила применения и закреплённые источники/лицензии. Runtime, API и CI gates не меняются.

### Добавлено
- FIN-372: отдельный источник Go CI и конфигураций линтеров для сервисов и библиотек FinAssist; workflows, bootstrap и общие regression tests перенесены из сервисного шаблона без изменения правил линтеров.

### Изменено
- FIN-421: ревью выбирает и читает существующие навыки из репозитория, подобранные по его назначению; источники, лицензии и выбор согласованы с AGENTS.md. Сохранены обязательные проверки и правило минимальной достаточной сложности. Runtime и публичный API не меняются.

### Исправлено
- FIN-372: проверка неизменяемости SQL-миграций отклоняет смену типа существующего файла (`T`, например замену симлинком).
